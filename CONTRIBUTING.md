# Contributing to Desktop X

Thanks for helping build Desktop X together!

## Before you code

1. Search existing issues and pull requests.
2. For substantial features or architectural changes, open an issue first.
3. Keep proposals focused on macOS usability, reliability, and performance.

## Development workflow

1. Fork the repository and create a feature branch.
2. Make a small, focused change.
3. Build and test with Xcode on macOS 14+.
4. Open a pull request with a summary, test steps, and screenshots if the UI changes.
5. A maintainer will review changes before merging.

## Pull request checklist

- [ ] Project builds successfully
- [ ] Existing drag-and-drop and desktop zone behavior still works
- [ ] New behavior is tested manually or automatically
- [ ] No credentials, personal files, or build artifacts are included
- [ ] Documentation reflects user-facing changes

Please be respectful and constructive. Maintainers may request changes or decline proposals to protect project quality.
