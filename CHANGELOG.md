# Changelog

All notable changes to DeskBox will be documented here.

## [0.1.0] - Unreleased

### Added

- Real-storage desktop file zones
- Multi-selection and native drag-and-drop
- Manual in-zone file ordering
- Quick Look preview
- Sticky notes
- Checklists
- Website / file / folder / app launchers
- Multiple workspaces
- Workspace switcher panel
- Workspace layout lock
- Layout snapshot save / restore
- File move history
- `⌘Z` undo for DeskBox file moves
- Recent operations view
- Configuration export / restore
- Configuration corruption recovery
- Missing-zone-folder protection
- Invalid launcher detection
- Glass-style settings and workspace UI
- Universal arm64 + x86_64 Release build support

### Changed

- Stable Bundle ID is now `com.wfb.deskbox`
- Existing data from `com.deskbox.prototype` migrates automatically

### Notes

- The open-source test release is ad-hoc signed and not Apple-notarized.
- Minimum supported system: macOS 14.
