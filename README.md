# Desktop X

A colorful, customizable desktop organizer for macOS.

Desktop X is an open-source native macOS app built with Swift and Xcode. It helps organize desktop items into customizable, collapsible zones and includes lightweight desktop utilities.

## Features

- Customizable desktop zones
- Drag-and-drop desktop item organization
- Collapsible sections
- Desktop notes and checklists
- Quick access to items

> Desktop X is under active development. Features and interactions may change.

## Requirements

- macOS 14 or later
- Xcode 27 recommended for source builds

## Build from source

1. Clone this repository.
2. Open `DeskBox.xcodeproj` in Xcode.
3. Select the app target and your Mac.
4. Build and Run.

The Xcode project and some internal identifiers currently retain the working name **DeskBox**.

## Download

Once an official release is published, download the app from the repository's **Releases** page. Until then, build from source.
